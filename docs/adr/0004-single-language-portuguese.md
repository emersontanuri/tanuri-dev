# Portuguese only, with content shaped for a locale layer

tanuri.dev is Portuguese. No internationalisation module is installed, and there is no English version.

The source material and the owner's voice are Portuguese, and a machine-assisted translation would flatten the writing, which is one of the site's genuine assets. The trade-off is real: an English-only reader, including a recruiter outside Brazil, cannot read the site at all. Content is therefore organised so a locale layer can be added without restructuring, and this decision should be revisited before the copy is finalised, because translating a written site is far more expensive than structuring for one now.

The owner's signature lines are quoted verbatim and stay in the language he wrote them in, which is English: the positioning statement, and the five questions of the Cadeia de pensamento. Rewriting them in Portuguese would replace his voice with a translation's. Portuguese-only therefore governs the prose the site writes for itself — explanations, headings, labels and descriptions — not the lines quoted from him.
