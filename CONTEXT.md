# tanuri.dev

Site pessoal de Emerson Tanuri. O contexto é o corpo de trabalho apresentado publicamente e o vocabulário usado para descrevê-lo: `Planning + Data + Decision Science + AI → Better Decisions`.

## Linguagem

**Projeto**:
Uma peça de trabalho com um problema declarado, um método e um resultado, apresentada com página própria no site.
_Avoid_: case study, portfolio item, side project, hobby project.

**Tipo de projeto**:
A classificação única que separa trabalho entregue de exploração. Um entre: Produto, Estudo, Experimento, Laboratório, Infraestrutura.
_Avoid_: categoria, tag, área.

**Produto**:
Um projeto entregue e usado por pessoas fora do ambiente de quem o construiu.
_Avoid_: app, SaaS, sistema.

**Estudo**:
Um projeto que aplica um método quantitativo a um problema real de planejamento, sem ser produto.
_Avoid_: pesquisa (reservado para investigação), análise.

**Experimento**:
Uma arquitetura exploratória que testa uma ideia, sem compromisso de continuidade.
_Avoid_: protótipo, POC, rascunho.

**Laboratório**:
Uma coleção de experimentos sobre um mesmo tema, mantida como corpo de trabalho.
_Avoid_: playground, coleção.

**Infraestrutura**:
Ambiente próprio mantido para desenvolver, hospedar e operar projetos.
_Avoid_: servidor, backend, cloud.

**Capacidade**:
Uma das quatro áreas de atuação apresentadas em profundidade: Planning, Data & Analytics, Decision Science, Software Engineering.
_Avoid_: skill, competência, especialidade, área de conhecimento.

**Cadeia de pensamento**:
A sequência de cinco perguntas que ele percorre, cada uma associada à disciplina que a responde.
_Avoid_: fluxo de trabalho, processo, metodologia, framework.

**Trilha**:
O caminho profissional apresentado como sequência coerente, de Administração a AI + Software.
_Avoid_: carreira, timeline, histórico profissional.

**Fluxo**:
Um diagrama de setas, autorado como conteúdo, que representa uma cadeia de etapas.
_Avoid_: diagrama, gráfico, fluxograma.

**Etapa**:
Uma unidade de um Fluxo, apresentada na ordem em que a cadeia a percorre.
_Avoid_: passo (_reservado à Cadeia de pensamento_), nó, bloco, caixa.

**Pesquisa**:
Trabalho investigativo apresentado separadamente do trabalho comercial.
_Avoid_: projeto de pesquisa, paper, artigo.
